Tiny Caser is a small AutoHotkey script that lets you type in different sized letters, smaller than usual.

For superscript, use Ctrl+Page Up
For tiny caps, use Ctrl+Page Down

Both function similar to caps lock.  Pressing caps lock will also return you to normal letters.
